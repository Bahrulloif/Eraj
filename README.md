Для каждого: `Add` (с картинкой) → список → `GetById` → `Update` → `Delete`, плюс владение (чужой

- [x] 2.1 Car — проверено живьём 2026-09-04, полный цикл Add(с картинкой)/Get/GetById/Update(с
      картинкой и без)/Delete + владение (чужой Businessman → 403). **Нашёл и исправил 2 бага**:
      (1, коммит `c0326d4`, касается всех 11 типов) `Update` требовал картинку в каждом запросе
      (общий DTO с `Add`, не-nullable поле) — нельзя было поменять цену, не прислав фото; сделал
      `Images` необязательным во всех 11 `AddXDTO` + защитил 9 из 11 `Add`-методов от `null`
      (2 уже были защищены); (2, коммит `16fe7e2`) `AddCar`/`DeleteCar`/`GetMotorbike`/
      `UpdateMotorbike` при невалидных данных возвращали `BadGateway` (502) вместо `BadRequest`
      (400) — копипаст-опечатка; на практике недостижимо (`[ApiController]` перехватывает раньше),
      но всё равно поправил. Заодно выяснилось: маршруты `Car` называются иначе, чем у большинства
      контроллеров (`post/addCar`/`post/updateCar`/`delete/deleteCar` вместо `post/car`/`put/car`/

      в БД ничего не менялось (тихий no-op). Баг стал проявляться только после фикса `c0326d4`
